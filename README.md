# Unlikely

A tiny Chrome (and any Chromium browser) extension that removes all your likes on X (Twitter). Open your likes page, press **Start**, walk away.

Free, open source, no login, no data collected. See the [privacy policy](PRIVACY.md).

<img src="icons/icon128.png" width="64" alt="Unlikely icon" />

## Install

From the Chrome Web Store (works in Chrome, Brave, Edge and other Chromium browsers): _link coming once the listing is live_.

Or load it from source:

1. Clone this repo.
2. Open `chrome://extensions` (or `brave://extensions`, `edge://extensions`, …).
3. Turn on **Developer mode** (top right).
4. Click **Load unpacked** and pick this folder.
5. Pin the extension so its icon stays in the toolbar.

## Use

1. Go to your likes page: <https://x.com/i/history/likes> (or `x.com/<you>/likes`). The popup's **Open my likes** button takes you there.
2. Click the Unlikely icon and press **Start**.
3. Close the popup if you like. A small pill in the bottom-left corner of the page shows progress and has a **Stop** button.
4. Press **Stop** (in the popup or on the pill) whenever you want.

Keep the tab open. It can be in the background, but Chrome may slow down background tabs.

## How it works

- Finds liked hearts (`data-testid="unlike"`) in the timeline, clicks one at a time, and checks the heart actually flipped and didn't snap back.
- Scrolls to load more. When X's timeline stops loading, it reloads the page to get a fresh list and carries on. Two reloads in a row with nothing left means it's done.
- **Rate limits:** after 3 failed unlikes in a row (or an X error toast), it pauses for 2 minutes, then 4, 8, … up to 30 minutes, and resumes on its own.
- Stops by itself if you navigate away from the likes page.

### Settings

| Setting | What it does |
| --- | --- |
| Speed | Pause between unlikes: Careful ≈ 1 s, Normal ≈ 0.5 s, Fast ≈ 0.05 s (each ± 25 % jitter). Fast is the default. Slower settings hit rate limits less. |
| Stop after | Stop after N likes. Leave empty to remove all of them. |
| Ghost likes | Some old likes show up on the likes page with an empty heart. X still counts them, but clicking unlike does nothing. With this on, Unlikely likes them again and immediately unlikes them, which removes them for real. |

## Development

No build step. Edit the files, then hit the reload icon on the extension card in `chrome://extensions`.

```
manifest.json        MV3 manifest
src/content.js       the unliking engine + on-page progress pill
src/popup.*          toolbar popup
icons/               generated by scripts/make_icons.py (stdlib only)
test/                mock likes page + popup preview with stubbed chrome APIs
store/               Web Store listing copy, screenshots and promo tiles
```

**Testing without touching your account:** `test/serve.sh` serves a fake likes timeline with the real content script on it.

```bash
./test/serve.sh
```

Open `http://localhost:8765/i/history/likes/?total=25&ghostEvery=7`, then from the devtools console:

```js
await send({ type: 'start', settings: { speed: 'fast', ghosts: true } })
```

Query params: `total` (number of tweets), `ghostEvery` (every Nth tweet is a ghost like), `failAfter` (server rejects unlikes after N, to test the rate-limit cooldown).

To preview the popup in a normal tab, serve the repo root (`python3 -m http.server`) and open `/test/popup-preview.html?state=ready|running|cooldown|done|away`.

## Releasing

1. Bump `version` in `manifest.json`.
2. `./scripts/package.sh` builds `dist/unlikely-<version>.zip` (manifest, `src/`, `icons/` only).
3. Upload the zip in the Chrome Web Store developer dashboard. Listing text, permission justifications and privacy answers are in [store/LISTING.md](store/LISTING.md).
4. If the popup changed, re-render the screenshots with `./store/render.sh` (needs Chrome or Edge).

## Caveats

- This depends on X's page markup, which can change without notice. If it stops finding hearts, the `data-testid` selectors in `src/content.js` are the first thing to check.
- Automating actions may go against X's terms. Use it on your own account at your own risk.
- Not affiliated with X Corp.
